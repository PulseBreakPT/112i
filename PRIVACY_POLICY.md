# Política de Privacidade — Distrito 112

**Última atualização: 2 de outubro de 2026**

O Distrito 112 é um videojogo independente de gestão de emergências publicado por PulseBreakPT.

## 1. Analytics, publicidade e gravação de sessões

O Distrito 112 não utiliza PostHog, Google Analytics, publicidade comportamental, gravação de sessões ou perfis de marketing.

## 2. Dados guardados localmente

A carreira do jogador e as preferências de som são guardadas no armazenamento local do navegador (localStorage). Estes dados permanecem no dispositivo/navegador do utilizador e não são enviados para uma conta do Distrito 112.

O relatório de turno exportado pelo jogador é criado localmente no navegador e descarregado para o dispositivo.

## 3. Mapa e cálculo de rotas

O jogo utiliza cartografia baseada em OpenStreetMap através do OpenFreeMap e calcula percursos através do serviço público OSRM.

Os pedidos de cálculo de rotas contêm apenas coordenadas dos locais usados pela simulação. O Distrito 112 não pede nem envia a localização real do jogador para estes serviços.

Tal como em qualquer pedido web, os fornecedores externos e o serviço de alojamento podem receber metadados técnicos necessários para disponibilizar o serviço, como endereço IP, data/hora, navegador, user-agent e informação de rede.

## 4. Dados que não são pedidos pelo Distrito 112

O jogo não pede diretamente:

- nome real;
- endereço de email;
- número de telefone;
- contactos;
- fotografias ou vídeos;
- acesso ao microfone ou câmara;
- localização precisa do dispositivo;
- identificadores publicitários.

O projeto não vende dados pessoais.

## 5. Alojamento e fornecedores externos

A versão web é alojada através do GitHub Pages. O navegador pode estabelecer ligações diretas aos serviços necessários ao funcionamento do jogo, incluindo GitHub Pages, Google Fonts, OpenFreeMap/OpenStreetMap e OSRM.

Estes fornecedores podem aplicar as respetivas políticas de privacidade e manter registos técnicos de segurança e funcionamento.

## 6. Controlo dos dados

O jogador pode reiniciar a carreira nas Definições do jogo.

Para eliminar totalmente a carreira e as preferências armazenadas localmente, o utilizador pode apagar os dados do site através das definições de privacidade/armazenamento do respetivo navegador.

## 7. Crianças

O Distrito 112 não cria contas nem solicita dados pessoais a menores. Caso o funcionamento do projeto seja alterado para incluir contas, comunicação entre jogadores ou recolha adicional de dados, esta política deverá ser revista antes dessa funcionalidade ser disponibilizada.

## 8. Alterações

Esta política deve ser atualizada antes de serem ativados analytics, publicidade, contas de utilizador ou qualquer nova recolha de dados pessoais.
